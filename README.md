## התקנה — חד פעמי (כ-10 דקות)

### שלב 1: יצירת הדאטהבייס (גיליון Google)
1. נכנסים ל-https://sheets.google.com ויוצרים גיליון ריק.
2. נותנים לו שם, למשל: **"ציוד וידאו 42 — DB"**.
3. מהכתובת של הגיליון `https://docs.google.com/spreadsheets/d/<SHEET_ID>/edit`
   מעתיקים את ה-**SHEET_ID** — המחרוזת הארוכה בין `/d/` ל-`/edit`.

> אין צורך ליצור עמודות או גיליונות פנימיים — המערכת יוצרת אותם לבד בפעם הראשונה
> (`equipment` לציוד, `checkouts` להיסטוריית ההשאלות).

### שלב 2: יצירת הבאקאנד (Apps Script)
1. בתוך הגיליון: **Extensions ← Apps Script**. נפתח טאב חדש.
2. מוחקים את הקוד לדוגמה (`function myFunction() {}`).
3. מעתיקים את **כל** התוכן של הקובץ [`appscript.gs`](appscript.gs) ומדביקים בעורך.
4. בשורה למעלה מחליפים את `PASTE_YOUR_SHEET_ID_HERE` ב-SHEET_ID משלב 1.
5. שומרים (Ctrl+S). שם הפרויקט — מה שבא לכם.

### שלב 3: פרסום כ-Web App
1. לוחצים **Deploy ← New deployment**.
2. אייקון גלגל השיניים ← **Web app**.
3. הגדרות:
   - Description: `v1`
   - Execute as: **Me**
   - Who has access: **Anyone**
4. **Deploy** ← מאשרים הרשאות (Google יזהיר על "unverified app" — לוחצים Advanced וממשיכים, זה הסקריפט שלכם).
5. מעתיקים את כתובת ה-**Web app URL** שמסתיימת ב-`/exec`.

### שלב 4: חיבור הפרונטאנד
1. פותחים את [`config.js`](config.js).
2. מדביקים את הכתובת משלב 3 ב-`SCRIPT_URL`.
3. מדביקים את כתובת הגיליון ב-`SHEETS_URL` (בשביל כפתור "הגיליון" בכותרת).
4. פותחים את `index.html` בדפדפן — המערכת אמורה לעבוד. מוסיפים פריט ראשון לבדיקה 🎉

### שלב 5: פרסום לצוות (אופציונלי, חינם)
1. דוחפים את התיקייה לריפו GitHub.
2. בריפו: **Settings ← Pages** ← Source: ענף `main`, תיקיית `/` ← Save.
3. אחרי כדקה הכתובת תהיה: `https://<המשתמש-שלכם>.github.io/<שם-הריפו>/`
4. שולחים את הלינק למחלקה. זהו.

## ⚠️ עדכון הבאקאנד — חובה לקרוא

**כל פעם שמשנים את `appscript.gs` חייבים לפרסם גרסה חדשה** — Apps Script לא מתעדכן לבד:

1. מדביקים את הקוד החדש בעורך ← שומרים.
2. **Deploy ← Manage deployments ← ✏️ (עריכה) ← Version: New version ← Deploy.**
3. כתובת ה-`/exec` נשארת אותו דבר — אין צורך לגעת בפרונטאנד.

## 💡 טיפ: מניעת "התנעה קרה"

Apps Script "נרדם" ולוקח לו 3-5 שניות להתעורר בקריאה ראשונה. כדי שהמערכת תמיד תהיה זריזה:
- בעורך ה-Apps Script: **Triggers (⏰ בסרגל הצד) ← Add Trigger**
- Function: `keepWarm` · Event source: Time-driven · Every 10 minutes

## מוסכמות (למי שירצה להרחיב)

- כל פונקציית באקאנד מחזירה `{ success: boolean, message?: string, ...data }`.
- כל קריאה מהפרונט עוברת דרך `apiCall(action, params)` שב-`utils.js` — לא `fetch` ישיר.
- תאים בוליאניים נשמרים כ-`'כן'`/`'לא'` כדי שהגיליון יישאר קריא.
- מחיקת פריט היא "רכה" (`active='לא'`) — ההיסטוריה נשמרת.
- קטגוריות הציוד מוגדרות ב-`config.js` — קל להוסיף/לשנות.
